# Simple Interest Calculator

This project contains a simple interest calculator written in Bash.

## Description

The calculator computes simple interest based on three user inputs:

- Principal: the initial amount of money
- Rate: the annual rate of interest
- Time: the time period in years

The simple interest is calculated using the formula:

Simple Interest = Principal × Rate × Time / 100

## Usage

Run the script with:

./simple-interest.sh

Enter the principal amount, rate of interest, and time period when prompted.

## Example

For a principal of 1000, an interest rate of 5%, and a time period of 2 years:

Simple Interest = 1000 × 5 × 2 / 100 = 100

The total amount is 1100.
